================================================================================
  MATERIAL REQUEST · DISPATCH · RETURN TO STOCK — API REFERENCE
  Base URL: /api/v1/
================================================================================

All responses use this envelope:

  {
    "success": true | false,
    "message": "string",
    "data": { ... } | [ ... ],
    "pagination": { ... }          // list endpoints only
  }

Pagination (list endpoints):

  {
    "total_records": 0,
    "total_pages": 1,
    "current_page": 1,
    "page_size": 20,
    "next": null,
    "previous": null
  }

Refs in responses: send id in request; return id + name (and email/username where relevant).

  worker_name:   { "id": 5, "name": "John Smith" }
  dispatched_by: { "id": 1, "name": "Admin", "email": "...", "username": "..." }
  item:          { "id": 19, "name": "Portland Cement" }


================================================================================
  MATERIAL REQUEST
================================================================================

--------------------------------------------------------------------------------
1. List material requests
--------------------------------------------------------------------------------
GET /api/v1/material-requests/

Query:
  page=1
  page_size=20
  search=MR-00001          (optional)
  status=draft             (optional)
  requested_date=2026-06-02 (optional, YYYY-MM-DD)
  worker_name=5            (optional, worker user id)

Response data[]:
{
  "id": 1,
  "request_number": "MR-00001",
  "worker_name": { "id": 5, "name": "John Smith" },
  "requested_date": "2026-06-02",
  "status": "draft",
  "job_name": "Downtown Mall Renovation",
  "items_count": 2,
  "notes": "string",
  "created_at": "2026-06-02T10:30:00Z"
}

--------------------------------------------------------------------------------
2. Create material request
--------------------------------------------------------------------------------
POST /api/v1/material-requests/

Payload:
{
  "worker_name": 5,
  "requested_date": "2026-06-02",
  "status": "draft",
  "jobs": [
    { "job": 11 }
  ],
  "items": [
    { "job": 11, "item": 19, "quantity": 23 }
  ],
  "notes": "optional"
}

Response data: MaterialRequestDetail (see §4)

--------------------------------------------------------------------------------
3. Update material request
--------------------------------------------------------------------------------
PATCH /api/v1/material-requests/{id}/

Payload (all fields optional):
{
  "worker_name": 5,
  "requested_date": "2026-06-05",
  "status": "pending",
  "jobs": [ { "job": 11 } ],
  "items": [ { "job": 11, "item": 19, "quantity": 80 } ],
  "notes": "string"
}

Response data: MaterialRequestDetail (see §4)

--------------------------------------------------------------------------------
5. Dispatch materials (creates dispatch record)
--------------------------------------------------------------------------------
POST /api/v1/material-requests/{id}/dispatch/

Payload:
{
  "lines": [
    { "line_key": "1", "quantity": 10 }
  ],
  "extra_items": [
    { "item": 25, "quantity": 3 }
  ]
}

line_key rules:
  - item row id as string:        "1"
  - or job+item:                  "job-11-item-19"
  - or index fallback:            "idx-0"

Response data: MaterialRequestDetail (updated quantities, status, dispatch_ids, extra_dispatch_items)

Side effect: creates Dispatch record (see DISPATCH §2)

================================================================================
  RETURN TO STOCK
================================================================================

Flow:
  1. Operator loads returnable materials (grouped by MR item or extra)
  2. Operator submits return request
  3. Approver completes request → quantities credited to inventory

--------------------------------------------------------------------------------
1. Load returnable materials (operator)
--------------------------------------------------------------------------------
GET /api/v1/dispatches/worker-return-materials

Query:
  worker_name=5                              (required, worker user id)
  date_preset=today                          (today | yesterday | custom | material_request)
  date_from=2026-06-01                       (required when date_preset=custom)
  date_to=2026-06-03                         (required when date_preset=custom)
  material_request_id=1                      (required when date_preset=material_request)

Response data:
{
  "worker_name": { "id": 5, "name": "John Smith" },
  "date_from": "2026-06-03",
  "date_to": "2026-06-03",
  "material_request_id": null,
  "lines": [
    {
      "group_key": "mr:1:item:19",
      "item_id": 19,
      "item_name": "Portland Cement (Type I)",
      "material_request_id": 1,
      "material_request_number": "MR-00001",
      "is_extra": false,
      "dispatched_quantity": 10,
      "returned_quantity": 2,
      "returnable_quantity": 8,
      "pending_request_quantity": 0,
      "sources": [
        { "dispatch_id": 1, "line_id": 1, "returnable_quantity": 8 }
      ]
    },
    {
      "group_key": "extra:item:25",
      "item_id": 25,
      "item_name": "Extra Item Name",
      "material_request_id": null,
      "material_request_number": null,
      "is_extra": true,
      "dispatched_quantity": 3,
      "returned_quantity": 0,
      "returnable_quantity": 3,
      "pending_request_quantity": 0,
      "sources": [
        { "dispatch_id": 1, "line_id": 2, "returnable_quantity": 3 }
      ]
    }
  ]
}

Note: One row per item per material request (or per extra). Not repeated per dispatch.

--------------------------------------------------------------------------------
2. Submit return request (operator)
--------------------------------------------------------------------------------
POST /api/v1/dispatch-return-requests

Payload:
{
  "worker_name": 5,
  "lines": [
    {
      "dispatch_id": 1,
      "line_id": 1,
      "quantity": 5,
      "return_type": "unused",
      "reason": "Not used on site"
    }
  ]
}

return_type: unused | faulty

Response data:
{
  "id": 1,
  "request_number": "RR-00001",
  "worker_name": { "id": 5, "name": "John Smith" },
  "status": "pending",
  "lines": [
    {
      "dispatch_id": 1,
      "dispatch_number": "DSP-00001",
      "line_id": 1,
      "item_id": 19,
      "item_name": "Portland Cement (Type I)",
      "job_name": "Downtown Mall Renovation",
      "quantity": 5,
      "return_type": "unused",
      "reason": "Not used on site"
    }
  ],
  "requested_at": "2026-06-05T11:26:29Z",
  "completed_at": null
}

--------------------------------------------------------------------------------
3. List return requests (approver)
--------------------------------------------------------------------------------
GET /api/v1/dispatch-return-requests

Query:
  status=pending           (optional: pending | completed | rejected)
  worker_name=5            (optional)

Response data[]: DispatchReturnRequest (same shape as §2 response)

--------------------------------------------------------------------------------
4. Complete return request — return to stock (approver)
--------------------------------------------------------------------------------
POST /api/v1/dispatch-return-requests/{id}/complete

Payload: none

Response data:
{
  "id": 1,
  "request_number": "RR-00001",
  "worker_name": { "id": 5, "name": "John Smith" },
  "status": "completed",
  "lines": [ ... ],
  "requested_at": "2026-06-05T11:26:29Z",
  "completed_at": "2026-06-05T12:00:00Z"
}

Side effect: updates dispatch line restocked_quantity and material request restocked_quantity
